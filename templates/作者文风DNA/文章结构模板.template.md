## 模式 A：危机切入与即时打脸型（标准爽文单章）

```text
[开篇 300 字]
  → 冲突直接发生（债务上门/死敌堵路/灵药被夺），无大段前情铺垫
[中段 1,000-1,500 字]
  → 敌方压迫升级，主角试探性出手，底牌暴露一层
  → 金手指/功法产生意想不到的克制效果
[后段 800-1,200 字]
  → 瞬间反打，物理终结当前对手
  → 结算战利品与在场众人反应（侧面衬托）
[章末 200 字]
  → 发现更大势力的标记 / 战利品引发新的异变（留下追读钩子）
```

---

## 模式 B：探索蓄势与谜题解构型（中篇/过渡章）

```text
[开篇 300 字]
  → 主角抵达新地图或接取关键任务，以物理环境细节白描开篇
[中段 1,200-1,800 字]
  → 收集情报、与 NPC 交互（对白暗藏信息机锋）
  → 发现现场遗留的异常痕迹（登记为 FB-xxx 伏笔）
[后段 800 字]
  → 触发局部机关或遭遇潜伏暗哨，极速交锋并压制
[章末 200 字]
  → 核心机关/阵眼显现，危机倒计时启动
```

---

## 模式 C：多线交织与高潮总爆发型（分卷卷末）

```text
[开篇 500 字]
  → 战场全景与各方势力就位，各角色状态最后确认
[中段 2,000-3,000 字]
  → 分层突破：配角牺牲/阻击掩护 → 主角直面卷末终极 BOSS
  → 连续底牌博弈（3 轮攻防转换，压抑到极致）
[后段 1,000 字]
  → 终极绝杀（调动前文铺设的所有资源与伏笔）
[章末 300 字]
  → 尘埃落定，世界格局重塑，引出下一卷新世界线索
```
