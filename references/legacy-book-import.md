# 老书与断更草稿逆向接续协议（Legacy Book Import Protocol）

本规范用于当用户已有部分小说章节（10~100+ 章历史正文）时，快速逆向提取当前世界线状态并实现无缝续写。

---

## 一、 逆向提取四步法

```text
[导入历史正文] ──> [1. 关键截面反推] ──> [2. 状态与伏笔固化] ──> [3. 细纲无缝接续]
```

### 步骤 1：确立历史截面（Cut-off Point）
以导入的最后一章（第 $N$ 章）为截面，**只提取截至该章的当前事实**，禁止把未来设想当成已有设定。

### 步骤 2：核心角色快照反推（Character Snapshot Reverse）
为主角、核心反派和主要配角生成截至第 $N$ 章的状态快照：
- **Identity（身份）**：当前成立的真实身份与社会地位；
- **Location（坐标）**：第 $N$ 章结束时所处的具体物理位置；
- **Goal（当前目标）**：主角眼下正在执行的直接目标（如：参加明日拍卖会、解毒等）；
- **State（身心状态）**：伤势、功法瓶颈、声望与隐藏立场；
- **Abilities & Inventory（底牌与道具余额）**：当前随身携带的法宝、功法、灵石、保命符咒数量；
- **Relationships（人际关系网）**：与各方势力的恩怨、利益同盟或仇杀状态；
- **Known Information（已知信息）**：角色**本人**已经确切知晓的秘密（禁止混入作者上帝视角的全局真相）；
- **Open Threads（未结事项）**：身上挂着的待办线索。

### 步骤 3：未结伏笔与状态建档
自动初始化填入：
- `00_作品总览与设定.md`
- `01_世界观与战力体系.md`
- `02_核心角色档案与声纹表.md`
- `04_伏笔与状态追踪表.md`（将前文所有未回收的暗线整理为 `FB-xxx`，并记录最近 3 章滚动摘要）。

### 步骤 4：续写第 $N+1$ 章细纲推进
无缝调用 `/novel-dna write` 模式接续推进第 $N+1$ 章！

---

## 二、 残稿与断更处理原则

1. **最后一章为未写完残稿**：所有快照统一截至残稿前的最后完整章节；残稿作为下一章的草稿继续填充。
2. **避免历史冗余**：快照只记录“当前最新状态”，不把过去 100 章的流水账塞入上下文，确保模型 Token 极简且聚焦。
